# SpendWise

**SpendWise** is a simple personal finance management web application designed to help users track their income and expenses, organize financial transactions into categories, and understand their spending habits.

The application provides an easy way for users to monitor their finances, maintain transaction records, and make better financial decisions.

## Project Purpose

Many people find it difficult to keep track of their daily spending and manage their personal finances. Without proper records of income and expenses, it can be challenging to understand where money is going and make informed financial decisions.

SpendWise aims to solve this problem by providing a simple and user-friendly platform where users can record, manage, and review their financial transactions.

## Features

The application will include the following features:

- **User Registration and Login:** Users can create accounts and securely access their financial records.
- **Income Tracking:** Users can add, edit, and delete income records.
- **Expense Tracking:** Users can add, edit, and delete expense records.
- **Transaction Categories:** Users can organize transactions into categories such as food, transportation, education, and entertainment.
- **Dashboard:** Users can view their total income, total expenses, and remaining balance.
- **Transaction History:** Users can view their previous income and expense transactions.
- **Transaction Filtering:** Users can filter transactions by category or date.
- **Expense Charts (Optional):** Users can view a simple chart showing expenses by category.

## Technologies

The project will use the following technologies:

- **Next.js:** React framework for building the web application.
- **React:** For building reusable user interface components.
- **TypeScript:** For type safety and maintainable code.
- **Tailwind CSS:** For responsive and user-friendly styling.
- **MongoDB:** For storing user accounts and financial transactions.
- **Git and GitHub:** For version control and team collaboration.
- **Microsoft Teams:** For team communication and coordination.
- **Vercel:** For application deployment and hosting.

## Project Development

The project will be developed over a four-week period. Development will focus on implementing the essential expense-tracking features first, followed by interface improvements, testing, and deployment.
